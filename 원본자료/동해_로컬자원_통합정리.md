# 동해 로컬 자원 통합 정리

용도 리서치 결과를 하나의 위계로 통합한 자료집. 웹 이관과 발표 자료 제작의 원본으로 사용.
항목 이름, 위치, 여는 시간, 주제, 메인 메뉴, 목적, 로컬 여부, 타겟, 리뷰, 출처
원칙 원자료를 왜곡하거나 압축하지 않고 옮김. 목적과 타겟과 로컬 여부는 원자료의 영업시간과 메뉴와 검증 표기에서만 도출. 근거가 없으면 확인 안 됨으로 표기.

# 5. 정리 노트

## 5-1. 로컬 여부 등급 요약
- 검증 완료 현지 방송 출연 또는 노포 연혁 또는 현지인 단골 근거가 명확한 곳
- 추가 검증 필요 근거는 있으나 단일 출처이거나 영업 정보가 불명확한 곳
- 실존 확인 카페와 소품샵과 양조장과 상품처럼 판매와 운영이 확인되나 리뷰 근거는 제한적인 곳
- 인근 지역 동해시 밖의 자원으로 동해 브랜드와 분리해야 하는 곳

## 5-2. 확인이 필요한 항목
- 문화팩토리 덕장카페 수제 캔맥주의 제조원 위탁생산 여부
- 영업시간과 가격이 확인 안 됨으로 표기된 항목 다수, 웹 이관 전 네이버 플레이스 재확인 필요
- 야시장은 여름 금요일과 토요일 계절 한정 운영, 상시 운영이 아님
